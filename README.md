# Golden Pace: Daily Vitality & Wellness Tracker

A single-file, mobile-first web app for older adults to log blood pressure, weight, exercise,
hydration and meals, run guided tai chi / bike / dumbbell routines, and take simple balance and
chair-stand tests. Data stays on the device (IndexedDB); export a CSV for a doctor visit or a
JSON backup from the Vault menu.

**Run it:** open `index.html` in a browser (internet needed for the Tailwind, Chart.js, Dexie and
confetti libraries loaded from CDNs).

**Meal analysis (optional):** add a Google Gemini API key under Settings. The key is stored only in
your browser's local storage and is never part of this repository.

Golden Pace is a personal logging tool, not medical advice.
